1. src/ingest/demo.ts (pure data + pure functions, no spawning):
   export const DEMO_NAMES = ['mandelbrot', 'life', 'cellauto', 'gradients', 'testsrc2'] as const (same list and order as src/cli/args.ts DEMOS; import that list from args.ts instead of duplicating it if it is exported, otherwise export it from demo.ts and leave a note in your report).
   export interface DemoSource { name; description; width; height; fps: 30; durationSec: 60; videoFilter: string; audioFilter: string }
   - Every video filter is an ffmpeg lavfi source string with explicit size, rate=30 and duration=60, chosen to look good at small sizes:
     mandelbrot (slow zoom), life (colored cells, scaled up with neighbor so cells stay crisp), cellauto (rule 30 or 110, colored),
     gradients (several moving colors), testsrc2. All at 640x360 or a source size that scales to it without blur artifacts.
   - Every audio filter is an `aevalsrc` (or `sine` mix) expression, 48 kHz stereo, duration=60, quiet (peak <= -12 dBFS), and distinct per demo
     (e.g. a slow chord for mandelbrot, clicks on a beat for life). No samples, no files.
   - export function demoVideoInputArgs(src): string[]  -> ['-f', 'lavfi', '-i', src.videoFilter]
   - export function demoAudioInputArgs(src): string[]  -> ['-f', 'lavfi', '-i', src.audioFilter]
   - export function getDemo(name): DemoSource (throws RangeError for unknown names).
   - export function demoMetadata(src): MediaInfo -> { width, height, fps, durationSec, hasAudio: true, source: 'demo' }.
     Import MediaInfo from src/ingest/media-info.ts (already exists, owned by architect-opus; do not edit it).

   - Writes assets/demo-<name>.mp4: H.264 yuv420p (libx264, -preset veryfast, -crf 20) + AAC 160k, 1280x720 or the source size, 30 fps,
