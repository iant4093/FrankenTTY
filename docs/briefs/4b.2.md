1. scripts/build-release.sh (bash, shellcheck-clean, set -euo pipefail, cd repo root, logs to build/logs/release.log, PASS/FAIL lines and
   RESULT: like scripts/test.sh). Usage: `bash scripts/build-release.sh [--targets all|host] [--node-version 26.13.0]`.
   - `npm run bundle` -> dist/frankentty.cjs.
   - Download official Node binaries for each target from https://nodejs.org/dist/v$V/ into build/node-cache/ (reuse if present):
     darwin-arm64, darwin-x64 (.tar.gz), linux-x64, linux-arm64 (.tar.xz), win-x64 (.zip). Verify every archive against SHASUMS256.txt
     (fail hard on mismatch). Extract only the node binary.
   - The BUILDER node (the one running --build-sea) must be an official binary for the HOST (download it too); never the Homebrew one.
   - For each target: sea config {main: dist/frankentty.cjs, output, executable: <target node>, disableExperimentalSEAWarning: true,
     useCodeCache: false, useSnapshot: false}; `<host official node> --build-sea cfg`. macOS outputs: `codesign --sign - --force` (skip
     with a warning when codesign is unavailable, i.e. not on macOS — then macOS targets must be skipped entirely, because arm64 macOS
     refuses unsigned modified binaries).
   - Package into release/:
       frankentty-macos-arm64.tar.gz, frankentty-macos-x64.tar.gz, frankentty-linux-x64.tar.gz, frankentty-linux-arm64.tar.gz
         (each containing a single executable `frankentty`, mode 755, plus LICENSE),
       frankentty-windows-x64.zip (frankentty.exe + LICENSE),
       frankentty.cjs (the npm-style bundle, for people with Node),
       install.sh, install.ps1 (copied from scripts/),
       SHA256SUMS over every file above (sha256sum or shasum -a 256, format "<hash>  <name>").
   - Smoke the host binary: `release/.../frankentty --version` equals package.json version.
   - --targets host builds only the host target (for fast local/CI smoke).
2. scripts/install.sh (POSIX sh, shellcheck -s sh clean; must work with `curl -fsSL URL | sh` and `sh install.sh --yes`):
   - Base URL: ${FRANKENTTY_RELEASE_BASE:-https://github.com/iant4093/FrankenTTY/releases/latest/download} (file:// allowed for tests).
   - Detect OS (Darwin/Linux) and arch (arm64/aarch64 -> arm64, x86_64/amd64 -> x64); unsupported -> clear error, exit 1.
   - Download the archive and SHA256SUMS with curl (or wget fallback), verify the archive's hash (sha256sum or shasum -a 256);
     mismatch -> error, exit 1, nothing installed.
   - Install to ${FRANKENTTY_INSTALL_DIR:-$HOME/.local/bin}/frankentty (create dir; atomic move). No sudo, ever.
   - If that dir is not on PATH, print the exact line to add for the user's shell (zsh: ~/.zshrc, bash: ~/.bashrc, fish: fish_add_path).
     Do not edit rc files.
   - FFmpeg check: if ffmpeg/ffprobe/ffplay are missing, print the install command (brew / apt / dnf / pacman / zypper) and, if a TTY is
     available (read from /dev/tty, because stdin is the script under curl|sh), ask "Install FFmpeg now? [y/N]"; --yes answers yes
     without asking; --no-ffmpeg skips. Only run the package manager command after a yes. With no TTY and no --yes: print and continue.
   - Print the uninstall line (rm the binary) and "Run: frankentty --demo".
