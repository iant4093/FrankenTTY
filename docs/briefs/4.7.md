  export function ensureDemoCache(demo: DemoSource, opts?: { dir?: string; ffmpegPath?: string; onReady?: (path: string) => void;
     onError?: (message: string) => void }): { entry: DemoCacheEntry; cancel(): void; pid: number | undefined }
     - If the cache file exists (and is non-empty, and its sidecar `.ok` marker exists), return ready: true immediately (onReady is called
       on the next tick for consistency).
     - Otherwise spawn ONE background ffmpeg (argv array, no shell, windowsHide, stdio ignore except stderr tail) that renders the demo's
       video and audio filters to `<path>.partial.mkv`: video libx264 -preset ultrafast -tune zerolatency? (no: use -preset veryfast,
       -crf 18, -g 15 -keyint_min 15 so any seek decodes at most 0.5 s), yuv444p is NOT required: use yuv420p; audio pcm_s16le 48 kHz stereo
       (no lossy codec, cheap to seek). On success rename atomically to the final path and write the `.ok` marker, then onReady(path).
       On failure delete the partial and call onError once.
     - Lower its CPU priority (os.setPriority(pid, 10) where supported; ignore errors) so it does not steal from playback.
     - cancel() kills it (src/ingest/kill-tree.ts killTreeSync) and deletes the partial. Idempotent.
     - Concurrent runs: if another process is already writing the partial (it exists and was modified < 60 s ago), do not start a second
       render; poll every 500 ms for the final file for up to 120 s, then give up quietly (entry stays not ready).
