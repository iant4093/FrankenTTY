1. src/renderer/downsample.ts
   downsampleHalfblock(src: Uint8Array, srcWidth: number, srcHeight: number, dst: Uint8Array): void
   - src is RGB24 at decode resolution (2c x 4r); dst is RGB24 at half-block resolution (c x 2r). Each dst pixel is the rounded mean of its
     2x2 source block, per channel, integer math. No allocation. Throw RangeError if sizes don't divide or dst is too small.
2. src/renderer/halfblock.ts — the NAIVE baseline (Wave 3 adds RLE/deltas on top; keep it as `naive` mode for --bench later)
   createHalfblockSerializer(cols, rows) -> { serializeNaive(pixels: Uint8Array /* c x 2r RGB24 */, offsetX, offsetY): Buffer, capacity }
   - One preallocated Buffer of 41*c*r + 12*r + 64 bytes per serializer (geometry change -> new serializer).
   - Output: SYNC_BEGIN; for each row: CUP(offsetY + row + 1, offsetX + 1); for each cell: `CSI 38;2;R;G;B m` (top pixel) +
     `CSI 48;2;R;G;B m` (bottom pixel) + `▀` (E2 96 80); then SGR_RESET + SYNC_END. Returns a subarray (no copy).
   - Write with a byte cursor and the decimal byte table (extend sequences.ts with whatever byte writers you need; no template strings,
     no Buffer.from, no join per frame). Escape bytes come from sequences.ts constants.

4. src/player/controller.ts
   createPlayer(deps: { stdout, stdin, screen, mediaInfo: MediaInfo, inputArgs: string[], isFile: boolean, fps: number,
     cellAspect: number, loop: boolean, now?: () => number }) -> { start(): Promise<number /* exit code */> }

   - Decoder: createDecoder at decodeWidth x decodeHeight (round each up to even if needed; that is already 2c x 4r), fps, startSec.
   - Pacing (REQ-SYNC-02): wall clock anchored at playback start. A setTimeout chain schedules tick n at anchor + n * (1000/fps)
     (schedule from the anchor, not from "now", so it never drifts). On each tick: due = floor((now - anchor) * fps / 1000) + 1 frames
     should have been shown; take frames with takeOldest() until `shownIndex` reaches due (frames passed over are counted as dropped);
     render only the last one taken. If stdout.writableNeedDrain is true, skip rendering this tick (count it) but keep consuming frames.
   - Render path per frame: downsampleHalfblock into a preallocated buffer -> serializeNaive -> one stdout.write.
   - Position = startSec + shownIndex / fps.
   - End of stream (decoder onEnd and queue empty): if loop, restart at 0 with a new generation; else resolve 0.
   - Resize (REQ-TERM-02): stdout 'resize', debounced 150 ms -> stop decoder, recompute geometry, CLEAR, new decoder with
     startSec = position and generation + 1, re-anchor the clock at the new start.
   - Keys: 'q' resolves 0, byte 0x03 resolves 130. Ignore everything else for now (Wave 4 adds the input router).
   - screen.addCleanup(() => decoder.killNow()) for whichever decoder is current.
   - Counters kept for the Wave 4 HUD: framesRendered, framesDropped, ticksSkipped, bytesWritten.
