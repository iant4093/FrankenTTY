1. src/audio/clock.ts — createClock({ now?: () => number (ms, default performance.now), offsetMs?: number (av-offset, default 0) }) -> Clock
   Clock: start(atSec), pause(), resume(), seek(sec), position(): number (seconds, never negative), isPaused(), and
   anchor(atMs?): re-anchor so position() == current position at time atMs (used when audio actually (re)starts).
   position() while running = startSec + (now - anchorMs + offsetMs) / 1000, clamped at >= startSec - 0 (no negative time).
   Paused: frozen. seek while paused stays paused at the new time. Pure apart from now().
2. src/audio/player.ts — createAudioPlayer({ inputArgs: string[] (['-i', path] or demo lavfi audio args), ffmpegPath?, ffplayPath?,
   volume?: 0..100 (default 100) }) -> AudioPlayer
   - play(atSec): kills any current pair, then spawns `ffmpeg -hide_banner -loglevel error -nostdin [-ss atSec] <inputArgs> -vn -sn -dn
     -ac 2 -ar 48000 -f wav pipe:1` and `ffplay -hide_banner -loglevel error -nodisp -autoexit -volume V -i pipe:0`, piping ffmpeg stdout
     into ffplay stdin (stream pipe; both spawned with argv arrays, no shell, windowsHide). Returns the spawn time (ms, same clock source
     as `now`) so the caller can anchor the clock.
   - stop(): Promise<void> kills both with killTree (taskkill /T on Windows), idempotent; killNow(): sync version via killTreeSync for
     exit paths. Destroy the pipes so nothing lingers.
   - onEnd(cb) when ffplay exits on its own (end of audio). onError(cb) with a one-line message (stderr tail).
   - If ffplay is missing (ENOENT), play() reports onError once and becomes a no-op; the caller falls back to wall clock.
   - ffplay inherits no stdin from the terminal (it must never read the user's keys) and no stdout (stdio ['pipe','ignore','pipe']).
