TASK 5.2 (Wave 5) — README screenshots rendered from FrankenTTY's real output.
From: architect-opus. To: builder-sonnet.

Goal: 4 README images in docs/screenshots/ (TruongCam style: .webp, 2x2 table), produced by a repeatable script from the real pipeline
output, so they are honest and need no manual screen capture. Ian may later replace them with Apple Terminal captures.

FILES: scripts/render-screenshots.ts (run with `node scripts/render-screenshots.ts`), scripts/lib/png.ts (zero-dependency PNG encoder
using node:zlib deflate + CRC32), scripts/lib/raster.ts, tests/unit/png.test.ts, tests/unit/raster.test.ts, docs/screenshots/*.webp
(generated output — you may write it; it is allowed for this task even though docs/ is otherwise architect-owned).

Method:
1. For each shot, decode ONE frame with the real decoder from the demo seek cache or lavfi at a chosen time, run it through
   src/player/pipeline.ts at 120x35 (HUD row hidden: render 120x34), 24-bit unless noted, default threshold, and replay the bytes into
   @xterm/headless 120x34.
2. Rasterize the emulator's cell buffer: cell = 8x16 px (2:1, matching the measured Apple Terminal aspect 2.016 closely enough):
   - '▀': top 8x8 = fg RGB, bottom 8x8 = bg RGB. ' ' : 8x16 bg. These are exact for half-block.
   - Braille U+2800..U+28FF: bg fill, then each set dot as a filled 2x2 (or 3x3) square in fg on a 2-col x 4-row dot grid inside the cell.
   - ASCII ramp chars ' .:-=+*#%@' only: hand-drawn 8x16 1-bit bitmaps you define in raster.ts (your own drawings, no third-party font),
     fg on bg.
   - Palette indexes (256/16) -> RGB via src/renderer/color-depth.ts toRgb.
   Output 960x544 RGB, then frame it: 24 px dark border (#1e1e1e) with a 28 px title bar showing three traffic-light dots (no text), to look
   like a terminal window. Final ~1008x596.
3. Encode PNG (scripts/lib/png.ts), convert to WebP with ffmpeg (`-c:v libwebp -lossless 0 -q:v 90`), write docs/screenshots/<name>.webp,
   delete the PNG.
Shots:
   - halfblock.webp: mandelbrot at 20 s, truecolor
   - braille.webp: life at 8 s, --mode braille
   - ascii.webp: cellauto at 10 s, --mode ascii
   - amber.webp: gradients at 15 s, --palette amber
Print each file's size; keep each under 300 KB (raise -q or lower if needed).
Tests: PNG encoder (signature, IHDR fields, CRC of a known chunk, round-trip through `ffmpeg -i x.png -f rawvideo` for a 3x2 image);
raster (one ▀ cell -> exact 8x16 pixels; one Braille cell with dots 1 and 8; '@' bitmap non-empty and ' ' empty).
