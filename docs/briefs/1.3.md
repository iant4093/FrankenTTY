API (pure, no I/O, no allocation beyond the returned object):

  computeGeometry(input: {
    srcWidth: number; srcHeight: number;   // integers >= 1
    cols: number; rows: number;            // terminal size, integers >= 1
    hudRows?: number;                      // default 1 (REQ-GEO-02: always reserved)
    cellAspect?: number;                   // cell height / width, default 2.0, valid 1.0..3.0
    maxCells?: number;                     // optional cap, integer >= 1
  }): Geometry

  Geometry = { renderCols, renderRows, offsetX, offsetY,      // cells, 0-based offsets into the terminal grid
               halfblockWidth, halfblockHeight,              // = renderCols, 2*renderRows
               decodeWidth, decodeHeight,                    // = 2*renderCols, 4*renderRows (Braille base, REQ-INGEST-02)
               availCols, availRows }                        // = cols, max(0, rows - hudRows)

ALGORITHM (exact, so the properties are testable):
  want = srcWidth / srcHeight; a = cellAspect.
  A rectangle of c x r cells shows physical aspect c / (r * a).
  1. Width-limited try: c = availCols, r = round(availCols / (a * want)).
     If 1 <= r <= availRows, use it.
  2. Otherwise height-limited: r = availRows, c = clamp(round(availRows * a * want), 1, availCols).
  3. If r was 0 from step 1 (very wide source), r = 1.
  4. If maxCells is set and c*r > maxCells: scale down keeping aspect. Let s = sqrt(maxCells / (c*r)).
     Width-led candidate: c' = max(1, floor(c*s)), r' = max(1, round(c' / (a*want))); while c'*r' > maxCells, decrement the larger
     of c', r' (keeping >= 1). Use the result.
  5. If availRows is 0 or availCols is 0, return renderCols = renderRows = 0 and all derived sizes 0 (callers show "terminal too small").
  offsetX = floor((availCols - c) / 2); offsetY = floor((availRows - r) / 2).
  Throw RangeError for non-integer or < 1 src/cols/rows, cellAspect outside [1, 3], or maxCells < 1.
