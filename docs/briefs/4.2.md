1. src/tui/input.ts — createKeyRouter({ onKey: (key: KeyEvent) => void, escTimeoutMs?: 50, setTimer?/clearTimer? (injectable) })
   -> { feed(bytes: Uint8Array): void, flush(): void (emit a pending lone ESC now), dispose() }
   KeyEvent = 'toggle-pause' | 'quit' | 'interrupt' | 'cycle-mode' | 'cycle-palette' | 'toggle-hud' | 'seek' (with deltaSec) | 'escape'
     (model it as a discriminated union: { type: 'seek', deltaSec: -30 | -5 | 5 | 30 } etc.)
   Bytes: ' ' toggle-pause; 'q'/'Q' quit; 0x03 interrupt; 'm'/'M' cycle-mode; 'c'/'C' cycle-palette; 'i'/'I' toggle-hud;
   Left: CSI D, SS3 D (ESC O D), CSI 1;1D; Right: CSI C, SS3 C, CSI 1;1C; Shift+Left: CSI 1;2D, CSI 2D; Shift+Right: CSI 1;2C, CSI 2C.
   Other CSI/SS3 sequences (any final byte 0x40-0x7E after parameters 0x30-0x3F and intermediates 0x20-0x2F) are consumed and ignored.
   A lone ESC becomes 'escape' after escTimeoutMs with no follow-up byte, or on flush(). UTF-8 multi-byte input is consumed and ignored.
   Never throws; bounded internal buffer (drop and resync after 64 bytes of an unterminated sequence).
2. src/tui/hud.ts — pure HUD renderer into a caller buffer (no allocation per call):
   createHud(cols) -> { render(state: HudState, out: Buffer, offset: number, row: number /* 1-based */): number /* new offset */, capacity }
   HudState: { visible, playing: boolean, positionSec, durationSec | null, fps, kbPerSec, sgrSavedPct, qualityStep: number,
               colorLabel: '24-bit'|'256'|'16', mode: 'halfblock'|'ascii'|'braille', palette: name, message: string | null }
   Visible layout (one row, exactly `cols` columns, ASCII + '▶'/'⏸' only, padded with spaces; truncate from the right — keep the
   left part — when too narrow, never wrap):
     "▶ 0:12 / 1:00  30.0 fps  412 KB/s  -75% SGR  Q0 24-bit  halfblock truecolor  space ←/→ m c i q"
   If message is set, it replaces everything after the time ("▶ 0:17 / 1:00  » +5s" style; caller decides text).
   Duration null -> "--:--". Times >= 1 h as h:mm:ss.
   Colors: one SGR at the start (dim gray on black in 24-bit form is fine; HUD uses fixed 16-color SGR `CSI 0;37;40m` so it works on all
   depths), then text, then SGR_RESET. Position: CUP(row, 1).
   Hidden: CUP(row, 1) + SGR_RESET + EL (`CSI 2K`) to blank the row.
   The visible text width must be counted in terminal columns: '▶', '⏸', '←', '→' are 1 column each (they are not East Asian Wide);
   document that assumption.
