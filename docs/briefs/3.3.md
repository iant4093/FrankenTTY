1. src/renderer/palette.ts
   - PALETTE_NAMES = ['truecolor', 'amber', 'green', 'dmg'] (same order as src/cli/args.ts PALETTES; import it if exported).
   - createPalette(name) -> { name, apply(rgb: number): number, applyGrid(grid: CellGrid): void (in place on fg and bg) }.
   - truecolor: identity.
   - amber (1978 VT100 amber phosphor), green (P1 green phosphor): a FIXED ramp of 16 colors from near-black to the phosphor's peak
     (e.g. amber peak ~#FFB000, green peak ~#33FF33), slightly tinted shadows. apply(rgb) = ramp[ index by luma ], with luma from
     src/renderer/luma.ts (already exists, owned by architect-opus, DO NOT EDIT).
     Ramp index = nearest ramp entry by luma, so applying twice equals once (each ramp entry maps to itself: assert it).
   - dmg (4-shade handheld LCD): exactly 4 colors #0F380F, #306230, #8BAC0F, #9BBC0F by luma quartile, also idempotent.
   - All palettes: precompute a 256-entry luma->color lookup per palette at creation (no per-call allocation).
2. src/renderer/color-depth.ts — ColorMapper implementations (interface in cells.ts):
   - createTrueColorMapper(): depth 24, map = identity, toRgb = identity.
   - create256Mapper(): xterm 256 palette. Candidates: 6x6x6 cube (indices 16..231, levels 0, 95, 135, 175, 215, 255) and 24 grays
     (232..255, values 8 + 10*i). map(rgb) = nearest candidate by colorDistanceSq (from cells.ts) between the cube's nearest point and the
     gray ramp's nearest point (compute both candidates in O(1), pick the closer). toRgb(i) = the xterm default RGB for that index.
     Optional 32 KB cache keyed by 15-bit RGB is fine if it keeps map() fast; no allocation per call.
   - create16Mapper(): ANSI 16 colors with the xterm default RGB values (0..15). map = nearest by colorDistanceSq; toRgb = table.
   - createMapper(depth: 24 | 8 | 4) convenience.
