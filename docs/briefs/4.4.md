1. Pipeline: add setThreshold(n), setDepth(depth) (new mapper, invalidate). Mode/palette setters already invalidate.
2. Clock-driven pacing (REQ-SYNC-01/02): replace the controller's own anchor with an audio/clock.ts Clock. When audio is enabled
   (mediaInfo.hasAudio && ffplay available && !noAudio), audio.play(pos) returns spawn time; clock.anchor(spawnTime) so video starts with
   audio; --av-offset feeds the clock offset. Without audio, the clock runs on the wall clock. Due frame index =
   floor((clock.position() - decoderStartSec) * fps) + 1 frames of the current decoder; drop when behind (as today).
3. Keys (REQ-UI-01, REQ-SYNC-03, REQ-SYNC-05) via createKeyRouter on stdin (feed probe.passthrough bytes first, fixing the type-ahead
   finding):
   - toggle-pause: pause -> stop consuming frames (decoder backpressure holds ffmpeg), audio.stop(), clock.pause(), HUD shows ⏸.
     resume -> audio.play(pos) + anchor, clock.resume().
   - seek ±5/±30: target = clamp(pos + delta, 0, duration ?? +inf; for files with duration, clamp to duration - 0.5). Coalesce key
     repeats: apply 120 ms after the last seek key (accumulate deltas). Then restart decoder (new generation) and audio at target,
     clock.seek(target), invalidate pipeline, HUD message "» +5s 0:17" for 1 s. While paused, seeking shows the new frame (decode one frame
     and render it) and stays paused.
   - cycle-mode: halfblock -> ascii -> braille -> halfblock, skipping modes effectiveMode() rejects; HUD message names the mode for 1 s.
   - cycle-palette: truecolor -> amber -> green -> dmg; HUD message 1 s.
   - toggle-hud: show/hide (row stays reserved: REQ-GEO-02).
   - quit / interrupt: as today (0 / 130).
4. HUD (REQ-HUD-01): createHud(cols); render at most 4 times per second and whenever state changes, appended to the frame's write when a
   frame is written that tick (one write per tick total), otherwise written alone. fps = frames rendered in the last 1 s; KB/s = bytes
   written in the last 1 s; SGR saved % = 1 - sgrEmitted/naiveSgr over the last 1 s; qualityStep = governor level; colorLabel from
   current depth; message per above. Default visible.
5. Governor (REQ-PERF-01): createGovernor({ fps, baseThreshold, baseDepth, baseCells: renderCols*renderRows of the uncapped geometry,
   enabled: quality === 'auto' }). Each rendered frame: record(renderMs + write ms, now) — measure the stdout.write() call duration
   (it blocks on macOS TTYs). Ticks skipped because stdout was busy -> recordSkip(now). onChange: apply threshold and depth to the
   pipeline immediately; if maxCells changed, recompute geometry with maxCells (computeGeometry supports it), clear the screen, restart the
   decoder at the current position (audio keeps playing: no audio restart for a quality change), new governor baseCells stays the
   uncapped value. HUD shows "Q<n>".
6. Loop: at end, restart video at 0 and audio at 0 together.
7. Exit/fatal paths (Wave 1 finding): main must not hang if run() rejects after the screen is active: restore, print one line, and
   process.exit(1). All children (decoders, audio pair) are killed by screen cleanups (killNow).
8. main.ts: ffplay availability decides audio; --no-audio disables; warn once (before entering the screen) when audio is unavailable
   for a file that has audio.
