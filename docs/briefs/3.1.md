1. src/renderer/halfblock-cells.ts
   buildHalfblockCells(decodePixels, decodeWidth, decodeHeight, grid: CellGrid, work: Uint8Array, thresholdSq: number): void
   - Downsample with the existing downsampleHalfblock into `work` (c x 2r), then per cell: top = packRgb(top pixel), bottom = packRgb(bottom).
   - If colorDistanceSq(top, bottom) <= thresholdSq: glyph = GLYPH_SPACE, bg = bottom, fg = top (fg is ignored by the encoder for spaces).
   - Else glyph = GLYPH_UPPER_HALF, fg = top, bg = bottom. No allocation.
2. src/renderer/encoder.ts
   createEncoder({ cols, rows, offsetX, offsetY, mapper: ColorMapper }) -> Encoder
   Encoder = { encode(grid, thresholdSq): Buffer (subarray of a preallocated buffer, valid until next encode), invalidate(),
               readonly stats: FrameStats, readonly capacity: number }
   FrameStats (reset per encode): bytes, sgrEmitted, cellsWritten, cellsSkipped, cursorMoves, plus the NAIVE baseline for the same grid:
     naiveBytes and naiveSgr = exactly what src/renderer/halfblock.ts serializeNaive would emit for this frame (2 SGR per cell, CUP per row,
     same framing). Compute naiveBytes arithmetically from digit counts (no second serialization).
   Behavior:
   - Screen model: per cell the glyph, and the *mapped* fg/bg actually shown (for depth 8/4: the index; for 24: the packed RGB).
     After invalidate() (and on the first frame) the model is "unknown": every cell is written.
   - Delta: a cell is unchanged when glyph equals the model AND its mapped colors are within threshold of the model's shown colors
     (compare in RGB via mapper.toRgb for 8/4-bit; for spaces only bg matters). Unchanged cells extend a skip run.
   - Cursor: at each row where anything is written emit CUP(offsetY+row+1, offsetX+col+1) before the first written cell. Within a row,
     end a skip run of k cells with `CSI k C` if its byte length is smaller than reprinting those k cells with the current SGR state;
     otherwise reprint them (they are already in the model, so reprinting is safe). Never rely on autowrap (it is off).
   - RLE: emit a fg SGR only when the cell's mapped fg differs from the last fg the terminal is using AND the glyph needs fg (not a space);
     same for bg. "Within threshold" counts as equal for RLE too, and the model records the color actually in effect (the reused one), so
     error never accumulates beyond the threshold: |shown - source| <= threshold for every cell, every frame.
   - SGR forms by mapper.depth: 24 -> `38;2;R;G;B` / `48;2;R;G;B`; 8 -> `38;5;n` / `48;5;n`; 4 -> `3n`/`9(n-8)` and `4n`/`10(n-8)`.
     When both fg and bg change, emit ONE combined SGR (`CSI 38;2;…;48;2;… m`) — one sequence, fewer escape introducers.
   - Framing: SYNC_BEGIN … SGR_RESET SYNC_END. A frame with zero changed cells returns an EMPTY buffer (length 0), so the caller
     writes nothing; stats.bytes = 0.
   - Capacity: worst case per cell 3 (glyph) + combined SGR at depth 24 (2+ "38;2;255;255;255;48;2;255;255;255" + 1 = 36) + per-row CUP 12
     + framing 32. Allocate once; assert in tests that all-random frames never exceed it.
   - No allocation per frame (no template strings, Buffer.from, join; typed arrays only).
