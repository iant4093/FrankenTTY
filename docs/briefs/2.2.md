2. src/ingest/assembler.ts (pure; no I/O)
   - class FrameAssembler { constructor(frameSize: number, capacity = 4) } with a pool of capacity+1 preallocated Uint8Arrays of frameSize.
     push(chunk: Uint8Array): copies bytes into the fill buffer (Uint8Array.set with subarray; no allocation per chunk); each completed
     buffer goes into a FIFO queue. Returns the queue length.
     isFull(): queue length === capacity (decoder pauses its pipe then).
     takeOldest(): Uint8Array | null and takeLatest(): Uint8Array | null (drops older queued frames, counting them in `dropped`).
     A buffer returned by take* stays valid until the next take* call (it returns to the pool then).
     framesCompleted, dropped, and trailingBytes (bytes in the incomplete fill buffer) counters.
   - class GenerationalAssembler wraps it: start(generation: number, frameSize: number) resets everything (new pool if size changed);
     push(generation, chunk) ignores chunks whose generation !== current (counts them in staleChunks).
