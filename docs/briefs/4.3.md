API: createGovernor({ fps, baseThreshold, baseDepth: 24 | 8 | 4, baseCells: number, enabled: boolean, minCells?: 960 (e.g. 40x24),
  windowMs?: 1000, upAfterMs?: 3000, cooldownMs?: 1000 }) -> Governor
Governor:
- record(frameMs: number, atMs: number): void   // one sample per rendered frame: render + write time
- recordSkip(atMs): void                         // a tick where stdout was still busy (counts as an over-budget sample)
- level(): number                                // 0 = full quality
- settings(): { threshold, depth, maxCells | null } // what the pipeline/geometry should use at the current level
- onChange(cb: (settings, level) => void)        // fired only when the level changes
Levels (design.md section 5): 0 base; 1 threshold = base + 8; 2 threshold = base + 16; 3 depth 8 (only if baseDepth is 24, else skip);
4..8 maxCells = round(baseCells * 0.8^k) for k = 1..5, never below minCells (stop adding levels once minCells is reached).
Rules: budget = 1000 / fps. Over the last windowMs, if p90 of samples > 0.9 * budget (skips count as samples of 2 * budget), step down
one level, then wait cooldownMs before another change (cooldown also clears the window). If p90 < 0.5 * budget continuously for
upAfterMs, step up one level. With fewer than 5 samples in the window, do nothing. enabled = false (--quality max) -> always level 0.
Pure: no timers, no I/O, time only from the atMs arguments. Bounded memory (ring buffer of at most fps * windowMs / 1000 * 2 samples).
